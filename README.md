# Asscat — The Floating Gardens

A playable 3D browser platformer based on the supplied Sky Paws prototype. Guide a scarf-wearing cat across seven floating islands, collect golden fish, dodge or stomp dog patrols, rescue Miso, Mochi and Bean, and bring everyone to Cat Haven.

## Play and develop

Requires Node.js 22.12+ (or 20.19+).

```sh
npm ci
npm run dev
```

Open the local URL printed by Vite. For a phone on the same network, open the computer's LAN address on port 5173. Run `npm run build` for a static `dist/` website, or `npm run standalone` for `dist/asscat-3d.html`, a self-contained downloadable game. The standalone file requires no network requests. WebGL 2 must be available in the browser. No backend, accounts, analytics or remote assets are used.

## Controls

| Action | Phone | Keyboard |
| --- | --- | --- |
| Move in all directions | Drag the left joystick | WASD / arrow keys |
| Jump | Tap JUMP | Space |
| Activate wings | Tap again while airborne | Space again |
| Climb / glide | Hold / release the jump button | Hold / release Space |
| Pause | Top-right pause button | Esc / P |

Flight lasts at most three seconds per landing. Landing recharges wings. Gold fish lead across the gaps; kittens sit near the route. Landing on a later island saves a checkpoint and restores one heart. Falling or touching a dog costs one heart. Stomp dogs by landing on them. Losing all hearts allows a checkpoint retry that preserves rescued kittens and fish. You must rescue all three kittens to finish. Progress is session-only; reloading starts a new adventure.

HQ / LQ switches between capped resolution with shadows and lower resolution without shadows. The game pauses when the tab is hidden or loses focus. Portrait and landscape layouts include safe-area spacing and independent simultaneous movement/jump input.

## Project structure

- `src/game.js`: deterministic fixed-step movement, collision, flight and level state.
- `src/scene.js`: Three.js environment, procedural characters, camera, lighting and effects. Static scenery is batched by material.
- `src/main.js`: touch/keyboard controls, menus, HUD, procedural sound and application loop.
- `src/style.css`: responsive overlays and controls.
- `prototype/skypaws.html`: original supplied prototype, preserved unchanged.
- `tests/game.test.js`: gameplay regression checks.
- `scripts/standalone.mjs`: creates the network-free HTML build.

## Validation

`npm test` verifies the flight limit, recharge, pause, falling, checkpoints, collection, rescue requirements, dog stomps and the reachability of every island crossing. `npm run build` verifies the production bundle.

This is a first playable 3D level, not a finished commercial release. Browser checks use desktop Chromium with mobile viewport/input emulation; real Android GPU performance and device audio still need hands-on testing. No public website deployment is configured.

Three.js is used under its MIT license; its license is included with the installed dependency. Character art, scenery and sound are generated by the game code.
